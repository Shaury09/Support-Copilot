# Release Notes: v3.0

- Increased Standard tier API rate limits (see updated Rate Limits doc).
- Removed the legacy `/v1/files` endpoint entirely; `/v2/files` is now
  the only supported version.
- Added shared folder link expiration settings.
- Increased Pro plan storage from 500 GB to 1 TB at no extra cost for
  existing subscribers.
