# Release Notes: v2.3

- Added selective sync so users can choose which subfolders sync to a
  given device.
- Fixed a bug where SYNC-101 conflicts were not detected across timezones.
- Introduced device limit enforcement (see FAQ for current limits).
- Deprecated the legacy `/v1/files` endpoint; use `/v2/files` instead.
